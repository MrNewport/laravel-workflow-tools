# Changelog

- Validate, compare, graph, publish and export immutable Workflow definitions through PHP services and Artisan commands.
- Preview fingerprint-checked publications before applying them, and inspect JSON and human-readable diagnostics.
- Review versioned history with bounded replay and import diagnostics, accessible graph output and portable dates.
- Support PHP 8.3+, Laravel 12/13 and Workflow 1.0 with regression tests, minimum-dependency checks, static analysis and formatting.
